# Code of Conduct

specjutsu adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Report unacceptable behaviour privately to the maintainers through a
[GitHub security advisory](https://github.com/nabour-labs/specjutsu/security/advisories/new)
or by contacting a maintainer directly. All reports are reviewed promptly and
kept confidential.
